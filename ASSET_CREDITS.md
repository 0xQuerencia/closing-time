# Asset provenance

All market geometry, fixture meshes, fictional product packaging, signage, surface textures, normal/roughness maps, and refrigeration audio in this milestone are original project assets, generated by the source scripts under `tools/` with OpenAI Codex assistance.

- Models: Blender 5.2.3, glTF 2.0 / GLB export. Regenerate with `tools/blender/build_market.py`.
- Texture and signage artwork: deterministic Python/Pillow, `tools/textures/generate.py`.
- Typography rasterized into original artwork: DejaVu Sans (DejaVu Fonts, Bitstream Vera-derived free font license). The font file is supplied by the build machine, not bundled. License: https://dejavu-fonts.github.io/License.html
- In-engine labels use Godot's built-in default font.
- Audio: original synthesized electrical harmonics, `tools/audio/generate.py`; no samples or recorded third-party material.
